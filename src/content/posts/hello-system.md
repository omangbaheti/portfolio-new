Welcome to the first post on this system. Everything you're reading is written
in **plain markdown** — drop a `.md` file into `src/content/posts/` with a
`title` and `date` in the frontmatter, and it appears in the index. No CMS, no
admin panel, no build ceremony.

## Why markdown

Writing should happen at the speed of thought, and nothing gets out of the way
like a text file. This site renders:

- Headings and lists
- `inline code` and fenced code blocks
- Tables, blockquotes, and links
- Embedded media like the video below

## Embeds work too

Any iframe-friendly URL — YouTube, Vimeo, CodePen — can be dropped into the
frontmatter `embed` field, or written inline via raw HTML:

<div class="embed">
	<iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ" title="Demo video" allowfullscreen></iframe>
</div>

## The aesthetic argument

Old technical manuals didn't have gradients. They had hairline rules, mono
labels, and exactly one color reserved for exactly one meaning. That's not
nostalgia — that's a **design system with discipline**, and it's rarer now
than it was then.

> One practice: prototype in hardware, validate with users, ship in software.
